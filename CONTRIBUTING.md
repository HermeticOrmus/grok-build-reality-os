# Contributing

This repository is the Grok Build Reality OS: doctrine (`AGENTS.md`), Gold Hat, and the user-guide snapshot. Contributions must pass the [Gold Hat](https://github.com/HermeticOrmus/gold-hat-manifesto) filter (empower or extract?) and state intention (Mentalism).

## What makes a good contribution

- Grok Build examples, skill ports, or user-guide corrections that a stranger can follow
- Honest inventory: do not claim Claude-suite totals as this repo's depth
- Surgical diffs. No "while we're here" rewrites
- No live credentials. Placeholders stay `YOUR_*`

## Submitting

1. Fork `https://github.com/HermeticOrmus/grok-build-reality-os`
2. Branch: `feat/description` or `fix/description` (conventional commits)
3. Change only what the request needs. Update docs if behavior or claims change
4. Open a pull request to `main`

See [docs/QUALITY_LADDER.md](docs/QUALITY_LADDER.md) for L0–L5. Do not claim a rung the tree does not meet.

## Code of conduct

Follow the Gold Hat: empower, never extract. Speak directly. No performative language.
