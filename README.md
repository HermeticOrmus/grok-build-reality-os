## Quick Start for Grok Build Users

```bash
# Clone the full Reality OS for Grok Build
git clone https://github.com/HermeticOrmus/grok-build-reality-os ~/.grok/reality-os

# Copy the doctrine into your global or project
cp ~/.grok/reality-os/AGENTS.md ~/.grok/AGENTS.md
# or per project: cp ... .grok/AGENTS.md

# Install complementary Grok-native tools
git clone https://github.com/HermeticOrmus/grok-build-skills ~/.grok/skills/grok-build-skills
git clone https://github.com/HermeticOrmus/claude-exorcist ~/.grok/skills/claude-exorcist

# Start a session with the full system
# (Grok will pick up AGENTS.md + skills)
```

Never put real API keys in this repo. Use env vars / your local secrets store. Placeholders in the user guide are labeled `YOUR_*`.

See [`user-guide/01-getting-started.md`](user-guide/01-getting-started.md), [`user-guide/02-authentication.md`](user-guide/02-authentication.md), and [`AGENTS.md`](AGENTS.md).
