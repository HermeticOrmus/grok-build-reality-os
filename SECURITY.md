# Security

Report vulnerabilities privately to the HermeticOrmus maintainers (see [org profile](https://github.com/HermeticOrmus) / funding contacts).

Do not file public issues with exploit details.

## Scope

This repository is primarily doctrine, user guides, and documentation for Grok Build — not a networked service. Still:

- Never commit real API keys, tokens, or personal data. Use env vars / a local secrets store. Placeholders in the user guide are labeled `YOUR_*`.
- Skills and examples must stay free of live credentials.
- Prefer defensive, consent-respecting patterns (Gold Hat). Do not contribute exploit PoCs, dark spam messaging patterns, or surveillance tooling.
