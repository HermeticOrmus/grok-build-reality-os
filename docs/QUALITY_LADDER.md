# Quality ladder (L0–L5)

Working scale for public HermeticOrmus Grok Build repos. It is a hygiene and depth check, not a badge. Do not claim a rung the tree does not meet.

| Level | Meaning |
|-------|---------|
| L0 | Unpublished, or no landing a stranger can use |
| L1 | Public repo with README and LICENSE |
| L2 | Gold Hat stated; a start-here path exists |
| L3 | `SECURITY.md` linked from README; contributing describes *this* repo; inventory is honest |
| L4 | Suite map complete; broken links fixed; a Depth / quality section points here; no inflated claims |
| L5 | Depth-complete in its job: used and verified in real sessions, not stubs or unkept promises |

Sibling Libre*-Grok-Build packs use the same rungs. Their "melt depth" tables are inventory, not a substitute for this ladder.

## This repo (honest)

`grok-build-reality-os` is the doctrine hub: `AGENTS.md`, Gold Hat, and a 22-chapter Grok Build user-guide snapshot. Hermetic extensions are still marked to-be-expanded. The user guide is not a live mirror of [xai-org/grok-build](https://github.com/xai-org/grok-build).

This pass targets **L4 hygiene**. It does not claim L5.

## Gold Hat

Empower the reader. Never pad a level. If the honest answer is "not yet", say that.
